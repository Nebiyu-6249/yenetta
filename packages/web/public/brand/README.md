# Brand assets (web)

Drop the provided Yenetta logo files here:

- `yenetta-wordmark.png` — Latin "Yenetta AI" gold wordmark (web/app headers).
- `yenetta-mark-amharic.png` — Amharic "የነታ" mark with the flame.
- `flame-icon.svg` / `favicon.ico` — the flame is the app icon / favicon.

Until the real files are added, the UI falls back to a  emoji + the
`Yenetta AI` wordmark text (see `app/page.tsx`).
