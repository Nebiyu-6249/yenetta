# Brand assets (mobile)

Drop the provided Yenetta logo files here:

- `icon.png` — app icon (the flame mark).
- `splash.png` — splash screen art.
- `adaptive-icon.png` — Android adaptive icon foreground.

These are referenced from `app.json`. Until added, Expo uses default
placeholders; the brand color (`#B08A45`) and paper background (`#F7F7F5`)
are already wired so the app is on-brand.
